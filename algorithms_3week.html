Arithmetic Series
등차수열의 합 공식과 두 가지 증명 방법 — 대칭 더하기와 수학적 귀납법.
핵심 공식
0 + 1 + 2 + 3 + ⋯ + n = Σk = n(n+1) / 2
점근적 근사: ≈ n² / 2
각 항이 상수(보통 1)씩 증가하는 수열. 합을 구하는 공식은 O(n²) 알고리즘 분석의 핵심.
계산기 — 합산 시각화
55 Σk = 10 × 11 / 2 = 55 (정확), 근사: n²/2 = 50
▸ 항별 값 시각화 (k = 1 ~ n)
증명 방법
1 + 2 + 3 + ⋯ + (n-1) + n
+ n + (n-1) + (n-2) + ⋯ + 2 + 1
= (n+1) + (n+1) + (n+1) + ⋯ + (n+1) ← n개
합이 n(n+1)인데 수열을 두 번 더했으므로 → n(n+1)/2
  1. Base case: n=0일 때 Σk = 0 = 0(0+1)/2 ✓
  2. 귀납 가정: n에서 성립한다고 가정 — Σk = n(n+1)/2
  3. n+1 단계: Σ(k, 0→n+1) = (n+1) + Σ(k, 0→n) = (n+1) + n(n+1)/2
  4. = (n+1)·2/2 + n(n+1)/2 = (n+1)(n+2)/2 = (n+1)((n+1)+1)/2 ✓

Polynomial Series
k의 거듭제곱 합 공식과 일반화 — Σkᵈ ≈ nᵈ⁺¹/(d+1)
주요 공식 모음
Σk  = n(n+1)/2 ≈ n²/2
Σk² = n(n+1)(2n+1)/6 ≈ n³/3
Σk³ = n²(n+1)²/4 ≈ n⁴/4
일반화: Σkᵈ ≈ nᵈ⁺¹ / (d+1)
n → ∞ 일 때 상대 오차 → 0
Σkᵈ 계산기 — 정확값 vs 근사값
계산 버튼을 누르세요.
nΣkᵈ (정확)nᵈ⁺¹/(d+1) (근사)상대 오차(%)
오차 분석
d > 1이면 오차는 nᵈ/2 ≤ error < nᵈ 범위에 존재.
그러나 nᵈ ≪ nᵈ⁺¹ 이므로 상대 오차 → 0.
limn→∞ [ nᵈ⁺¹/(d+1) ] / [ Σkᵈ ] = 1
이 성질 덕분에 알고리즘 분석에서 Σkᵈ = Θ(nᵈ⁺¹) 으로 쓸 수 있다.

Train Rearrangement
T자형 철로(스택)를 이용한 기차 재배열 — 어떤 순열이 정렬 가능한가?
문제 설명
기차가 (a)에서 들어와 (b)(스택)를 거쳐 (c)로 나간다.
스택을 사용해 임의의 입력 순서를 (1, 2, 3, …, n) 으로 정렬할 수 있는가?
답: 항상 가능하다! 스택 1개로 n개의 기차를 순서대로 정렬할 수 있다.
스택이 2개라면? → 더 많은 순열이 정렬 가능하지만 모든 순열은 아니다.
인터랙티브 시뮬레이터 — (3,2,1,4) → (1,2,3,4)
입력 (a)
출력 (c)
↕ 스택 (b)
시뮬레이션 준비 완료. "다음 단계" 버튼을 누르세요.
스택 정렬 불가능한 순열
스택 1개로 정렬 불가능한 패턴: n-m-k (n > k > m) 패턴.
예) [2,3,1] — 3을 꺼내려면 2를 먼저 꺼내야 하는데 1이 아직 입력에 있음.
// 04
Catalan Number
스택 1개로 정렬 가능한 순열의 수 = n번째 카탈란 수 Cₙ.
카탈란 수 공식
Cₙ = C(2n, n) / (n+1) = (2n)! / ((n+1)! · n!)
n개 원소에서 스택 정렬 가능한 순열의 수
전체 n! 가지 순열 중에서 카탈란 수만큼만 스택 하나로 정렬 가능.
카탈란 수는 이진 트리의 개수, 괄호 쌍의 수 등 다양한 조합론 문제에 등장한다.
카탈란 수 vs 전체 순열 수
재귀적 정의
C₀ = 1,   Cₙ₊₁ = Σ(k=0→n) Cₖ · Cₙ₋ₖ
점화식으로도 계산 가능. 이 구조는 DP 알고리즘과 직결된다.
